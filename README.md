# Yamone-Games

야모네 앱에 나중에 통합할 미니게임 모듈 저장소입니다.

## 현재 게임
- 스도쿠
  - 난이도: 쉬움 / 보통 / 어려움 / 도전
  - 메모 / 지우기
  - 선택 칸 기준 가로·세로·3×3 영역 강조
  - 같은 숫자 강조
  - 타이머 / 일시정지
  - 자동 저장 / 이어하기
  - 유일해 검증 기반 문제 생성

## 구조
- `app`: 독립 APK 테스트용 호스트 앱
- `games/sudoku`: 야모네 본앱에 이식 가능한 스도쿠 모듈

향후 `games/nonogram`, `games/matching`, `games/number-puzzle` 등을 같은 방식으로 추가합니다.
