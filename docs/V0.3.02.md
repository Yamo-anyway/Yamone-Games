# 야모네 게임 v0.3.02

## 변경
- 홈/랭킹 배너를 화면 상단의 독립된 320×50dp 광고 슬롯으로 이동. 조작 UI와 10dp 간격. 광고 제거 권한이면 슬롯도 제거.
- 홈 대형 환영 배너 제거. 게임 선택 2열을 먼저 표시하고 광고 없는 시간을 그 아래에 표시.
- 빙하: 눈 덮인 상단, 청록색 결정 단면/균열/그림자. 실제 착지 위치와 상단 위치 유지.
- 물고기: 수면 빛줄기, 깊이감 있는 바다, 산호/해초, 가장자리 기포. 장식은 충돌에 참여하지 않음.
- 눈덩이: 오로라/설산/침엽수 배경, 굴러가는 질감, 보이는 덩어리 형태의 파편.
- 눈송이 표시 및 눈송이 충돌 판정 완전 제거. 3초 시작 보호, 화면 비율을 반영한 원형 충돌.
- 파편은 눈덩이에서 좌우로 서로 다른 거리로 퍼진 뒤 아래로 내려옴. 단계에 따라 거리/횟수 증가, 개수 제한 및 플레이어 근처 생성 금지.
- 나노초 프레임 간격을 누적, 1ms 고정 시뮬레이션/저장/표시. 화면 갱신과 입력 해상도의 제약이 있으므로 실제 사건의 1ms 절대 정확도를 보증하지 않음.
- 250ms 초과 화면 정체 시 자동 일시정지. 일시정지/앱 전환 시간은 기록에서 제외.

## 기록 호환성
기존 눈덩이의 초 단위 `records_snow_rush`는 보존하고 내 기록 아래에 별도 표시.
새 파편 규칙은 `records_snow_rush_shards_ms`에 정수 밀리초 저장.
서버도 기존 `snow_rush/normal`과 새 `snow_rush/shards_ms`를 분리. 규칙이 달라 기존 점수와 경쟁하지 않음.
다른 게임 기록/닉네임/광고 권한/설정은 그대로 유지.

## 온라인 정밀 랭킹 서버 업데이트
수정한 `cloudflare/ranking-worker.js`를 기존 Worker **yamone-games-ranking-api**에 배포해야 새 순위가 동작함.
기존 DB 바인딩 `DB`, `RANKING_SIGNING_SECRET`은 유지. 별도 SQL 마이그레이션이나 데이터 삭제는 필요 없음.
구형 앱의 초 단위 API와 기존 프로모션 API는 유지.
업데이트 전에는 새 앱이 서버 업데이트 필요 안내를 표시하고 로컬 기록/전송 대기를 유지함. 초 단위 API로 대체 전송하지 않음.
배포 확인: `/health` 응답의 `snowRushRules`에 `shards_ms`, `snowRushPrecision`에 `milliseconds`가 있어야 함.
이 작업의 로컬/CI 서버 테스트는 독립 SQLite DB를 사용했으며 운영 서버 배포를 의미하지 않음.
