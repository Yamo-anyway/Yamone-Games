# 야모네 게임 0.3.00

## 범위
기존 4개 게임(스도쿠, 빙하 점프, 물고기 냠냠, 눈덩이 피하기)의 공통 디자인·게임 화면·소리·진동·설정·랭킹을 개편한다. 물고기 일반/60초 타임어택 모드는 각각 독립 기록이다. `winterride`는 기존 미노출 모듈이며 이번 메뉴에 추가하지 않는다.

- 민트·핑크, 승인된 일러스트 카드, 2열 홈, 투명 캐릭터, 적응형 설치 아이콘.
- 배경/물체의 장식용 외곽선 축소. 스도쿠 9×9 격자와 3×3 구분선은 유지.
- 5개 오프라인 합성 배경음악, 7개 효과음. 각 재생 채널 ON/OFF·볼륨, 음악 분위기, 진동 ON/OFF·강도 선택, 무음 모드 준수.
- Activity 백그라운드·오디오 중단 시 게임과 소리 정지. 복귀 후 명시적 계속하기. 광고 표시 중 음악 중지. 설정은 별도 SharedPreferences에 보존.
- 게임별 시작·일시정지·종료 결과, 새 최고기록/남은 차이. 물고기 모드별 최고기록 기준.
- 랭킹 게임 선택, 물고기 모드 선택, 온라인/내 기록 구분, 상위 3명, 본인 강조, 내 주변, 단계별 더 보기, 로딩·오프라인·오류·빈 상태.
- 스도쿠: 난이도별 개인 기록만 표시. 서로 다른 퍼즐의 풀이 시간을 임의의 종합 온라인 점수로 합산하지 않는다.
- 순위 공유 선택을 앱 시작마다 ON으로 덮어쓰던 부분 제거. OFF/ON 정책과 선택 삭제 UI 유지. 전송 대기 중 더 좋은 기록이 생기면 이전 응답으로 새 대기 기록을 삭제하지 않는다.

## 변경하지 않은 사항
게임의 난이도/충돌/점수 규칙, 스도쿠 메모·지우기·숫자 고정·추측 저장/복귀, 기존 로컬 기록의 키와 파일 형식, 서버 API/스키마, 구매 권한 및 광고 운영 정책을 유지한다. 서버 Worker 배포는 이 UI 개편의 필수 단계가 아니다. 실사용 서버 연결·스토어 결제는 별도 운영 검증 대상이다.

## 회귀 확인
- 0.2.00 → 0.3.00 업데이트: 서명 동일 여부, 닉네임·완료 기록·스도쿠 메모·추측 저장 복원.
- 3개 아케이드 모두: 시작, 드래그, 일시정지, 계속하기, 앱 전환, 사운드 설정, 게임 종료, 다시하기.
- 물고기 일반/60초 모드의 기록이 섞이지 않는지 확인.
- 스도쿠 난이도 전환·메모·고정 숫자·추측 시작/종료/복귀·완료.
- 공유 OFF 재실행 유지, ON 시 저장 최고기록 게시, OFF 시 서버 삭제 대기, 게임별 선택 삭제.
- 음악/효과음/진동 독립 설정 저장; 무음/전화/헤드폰 분리/광고 중단; 없는 진동 장치에서도 정상 동작.
- 320dp 작은 화면 및 큰 글꼴: 게임 선택/설정 스크롤, 숫자/점수 잘림, 하단 광고·내비게이션 겹침.
- 진동 세기·음악 청감·실제 단말의 무음/통화 동작은 빌드 성공만으로 검증되지 않는다.

## 원복
원본 그대로: `archive/pre-0.3-original` (6770008244349cb6a1e3c43e43ac0a70113a38cd).
기준판: `release/0.2.00` (0664870ba7cd608b319346abad41760d44e1c628).
앱을 삭제하지 말고 기존 서명으로 기준판 소스를 더 높은 versionCode로 빌드한다. 예: 현재 30000이면 `gradle :app:assembleDebug -PyamoneVersionCode=40000`. 40000을 설치한 다음 개편판으로 되돌릴 때도 더 높은 코드가 필요하다. 향후 빌드 코드는 계속 증가해야 한다. 기존 0.2.00 APK를 바로 덮어쓰는 다운그레이드는 보장되지 않는다.
