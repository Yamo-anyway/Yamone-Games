# v0.3.04 — 2차: 눈덩이 러시

0.3.03의 홈·광고·스도쿠 변경을 보존한다. 이번에는 눈덩이 러시만 개편한다.

- 설산·오로라·설원을 담은 고정 배경 원화를 WebP 이미지로 앱에 직접 포함한다.
- 배경 원화에서 HUD·글자·캐릭터·눈덩이 등 고정된 게임 물체는 제거해 별도 게임 레이어와 분리한다.
- 눈덩이는 둥근 흰 눈 뭉치, 파편은 각진 연보라/청색 조각으로 표시한다. 모두 진한 외곽선과 그림자를 사용한다.
- 화면 아래 좌우 경계 브래킷은 실제 캐릭터 바깥 모서리의 이동 한계와 일치한다.
- 파편의 낙하 속도는 모체 눈덩이의 32~70% 범위에서 각기 다르게 정해지고, 이후 가속하지 않는다.
- 옆으로 퍼지는 힘도 다르게 감쇠하며, 생성 시 실제 2차원 이동 속도도 모체의 82%를 넘지 않는다.
- 시작 보호 3초, 6초 이후 파편 생성, 크기가 줄지 않는 눈덩이, 개수 상한, 밀리초 기록을 유지한다.
- 저장 포맷과 랭킹 프로토콜은 0.3.03과 동일하다. 운영 서버는 변경하지 않는다.

## 제작/검증 자료
배경은 이 대화에서 생성한 설경 일러스트를 사용해 게임 오브젝트를 분리하고 빈 설원으로 정리한 원화다.
앱은 `games/snowrush/src/main/res/drawable-nodpi/snow_aurora_304.webp`를 그대로 로드한다.
별도 생성된 홍보 콜라주에 보이는 물고기·빙하 등 3차 작업은 이번 버전에 포함하지 않는다.

## 버전/복귀
versionName 0.3.04, versionCode 30004, applicationId com.yamone.games.
기존과 같은 테스트 서명. 0.3.03은 release/0.3.03에서 복원할 수 있다.
기록을 보존하며 이전 소스로 돌아갈 때는 같은 서명으로 설치된 버전보다 큰 내부 코드를 사용한다.

## 테스트
눈덩이 엔진 테스트는 기존 12개와 신규 9개다. 전체 컴파일과 모든 모듈의 단위테스트는 CI 결과를 확인한다.
가상기기 테스트는 0.3.03→0.3.04 업데이트, 보존 기록, 경계 이동, 일시정지, 백그라운드 복귀,
기존 배너 정책, 다른 게임 진입, 좁은 화면을 검사한다. 실기기·실제 광고·운영 서버 검증과는 구분한다.
