# 야모네 게임 0.3.03 — 1차 개편

기준: 설치 제공된 v0.3.02 (af03fe9939cfce0d924e049aa3a59dd73633164b).
패키지 com.yamone.games, versionCode 30003. 동일 기존 서명으로 빌드.

홈의 우측 설정/부제/우리의 놀이터/내 기록 링크를 없애고 타이틀 우측에
광고 없음 HH:MM:SS와 둥근 재생 아이콘을 배치. 버튼은 기존의 선택형
광고 +30분 팝업으로 연결. 하단의 중복 시간 카드는 홈에서 제거.

광고 시간은 기존 ad_free_until 값 그대로 사용. 시간이 남아 있으면 모든
배너를 요청/표시하지 않음. 시간이 0이면 모든 화면의 공통 상단 슬롯에서
배너를 요청. 광고 미수신/오프라인/동의 미완료여도 게임은 항상 허용.
강제 전면광고 호출 제거. 영구 광고 제거 권한은 계속 최우선 적용하며
광고 타이머/버튼까지 숨김. 자동 누적 보상은 없고 기존 명시적 선택형 유지.
SDK 배너/보상형은 기존 Google 테스트 광고 ID를 사용.

스도쿠: 현재 보이는 숫자 기준의 행/열/3x3 중복 위치 강조. 입력 가능한
빈칸은 흰색, 겹치는 빈칸은 짙은 회녹색/회분홍색, 동일 숫자는 진한 색.
선택칸에 금색 테두리. 정답을 미리 알려주는 기능은 아님. 9x9 외곽선을
내부 선과 별도로 안쪽에 그려 모서리 잘림 방지. 입력/메모/추측 저장과
기록 포맷 및 난이도는 변경하지 않음.
