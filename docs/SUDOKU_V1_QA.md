# Yamone Sudoku V1 실기기 QA 체크리스트

대상 빌드: `0.2.0-qa1`

## 1. 설치 / 기본 화면
- [ ] 기존 테스트 APK 위에 정상 업데이트 설치된다.
- [ ] 홈 화면이 정상 표시된다.
- [ ] 민트 / 핑크 테마 전환이 즉시 반영된다.
- [ ] 아기물범 / 아기곰 선택이 정상 반영된다.
- [ ] 작은 화면에서도 하단이 잘리지 않고 필요할 때만 스크롤된다.
- [ ] 시스템 뒤로가기/제스처가 스도쿠·게임·기록·설정에서 홈으로 돌아간다.

## 2. 난이도 / 저장 슬롯
- [ ] 쉬움 / 보통 / 어려움 / 도전 전환이 된다.
- [ ] 난이도 변경 시 현재 게임을 임시저장하고 이동할 수 있다.
- [ ] 난이도별 저장 게임이 서로 섞이지 않는다.
- [ ] 저장된 난이도에는 `저장` 표시가 보인다.
- [ ] 앱을 종료 후 다시 열어도 마지막 진행 게임이 이어진다.

## 3. 일반 입력
- [ ] 빈칸 선택 → 숫자 입력이 된다.
- [ ] 정답 숫자는 정상 색으로 표시된다.
- [ ] 오답 숫자는 빨간색으로 표시된다.
- [ ] 오답을 여러 개 입력해도 남아 있는 오답은 모두 빨간색이다.
- [ ] 지우기로 사용자 입력 숫자와 메모가 지워진다.
- [ ] 주어진 숫자는 수정되지 않는다.

## 4. 메모
- [ ] 메모 ON/OFF가 정상 전환된다.
- [ ] 빈칸에 후보 숫자를 여러 개 넣고 뺄 수 있다.
- [ ] 정답 숫자 입력 시 같은 행·열·3×3 영역의 해당 메모가 자동 제거된다.
- [ ] 오답 입력 때문에 메모가 자동 제거되지 않는다.

## 5. 숫자 완료 / 강조
- [ ] 특정 숫자의 정답 위치 9칸이 모두 채워지면 숫자패드에 `✓`가 표시된다.
- [ ] 완료 숫자도 계속 선택할 수 있다.
- [ ] 선택한 칸의 가로·세로가 가장 먼저 눈에 들어온다.
- [ ] 같은 정답 숫자들이 있는 다른 가로·세로는 더 연하게 표시된다.
- [ ] 오답 숫자는 같은 숫자 안내선의 기준이 되지 않는다.

## 6. 숫자 고정
- [ ] `숫자 고정` 전환 후 숫자를 먼저 선택할 수 있다.
- [ ] 선택한 숫자가 진한 테마색으로 표시된다.
- [ ] 빈칸을 연속 터치하면 선택한 숫자가 연속 입력된다.
- [ ] 같은 숫자를 다시 누르면 고정이 해제된다.
- [ ] 메모 ON + 숫자 고정에서 후보 메모를 연속 추가/해제할 수 있다.
- [ ] 이미 `✓ 완료`된 숫자는 줄 확인용으로 선택되지만 빈칸에 오답으로 입력되지 않는다.

## 7. 추측 저장
- [ ] 쉬움에서는 추측 버튼이 보이지만 비활성이고 `보통부터` 안내가 보인다.
- [ ] 보통 / 어려움 / 도전에서는 `▶ 추측 시작`이 동작한다.
- [ ] 시작 후 같은 조작 영역에 `■ 추측 종료`, `↩ 돌아가기`가 보인다.
- [ ] 추측 시작 이후 숫자와 메모를 바꾼 뒤 `↩ 돌아가기` 하면 저장 시점으로 정확히 복원된다.
- [ ] 복원 후에도 같은 추측 지점이 남아 다시 다른 경우를 시험할 수 있다.
- [ ] `■ 추측 종료`를 누르면 현재 진행 상태는 유지되고 추측 지점만 사라진다.
- [ ] 추측 상태에서 앱을 종료 후 다시 열어도 체크포인트가 유지된다.

## 8. 타이머 / 일시정지 / 백그라운드
- [ ] 게임 화면이 활성 상태일 때만 타이머가 증가한다.
- [ ] 일시정지 시 타이머가 멈춘다.
- [ ] 홈 버튼으로 앱을 백그라운드로 보내면 타이머가 멈춘다.
- [ ] 화면을 잠근 동안 타이머가 증가하지 않는다.
- [ ] 다시 앱으로 돌아오면 기존 시간에서 이어진다.
- [ ] 백그라운드 이동 직전 진행 상태가 저장된다.

## 9. 클리어 / 기록
- [ ] 마지막 정답을 입력하면 즉시 클리어 화면이 뜬다.
- [ ] 난이도, 플레이 시간, 실수 횟수가 정상 표시된다.
- [ ] 완료 게임은 임시저장 목록에서 사라진다.
- [ ] 기록 화면의 총 완료 수가 증가한다.
- [ ] 해당 난이도의 완료 수와 최고 기록이 갱신된다.
- [ ] 최근 완료의 난이도·시간·실수 횟수가 맞다.
- [ ] 같은 날 여러 판을 완료해도 연속 플레이 일수가 잘못 증가하지 않는다.

## 10. V1 통과 기준
- [ ] 앱 강제종료/화면 깨짐 없음
- [ ] 저장 데이터 유실 없음
- [ ] 스도쿠 진행을 막는 입력 버그 없음
- [ ] 작은 화면에서 주요 버튼 접근 가능
- [ ] 민트/핑크 × 물범/곰 조합 모두 시각적으로 문제 없음
- [ ] 최종 캐릭터 이미지 적용 전 기능 QA 통과

## 실기기에서 특히 볼 것
1. `숫자 고정 + 메모 ON`을 1~2분 실제로 사용해보기
2. 추측 저장 후 A → 복원 → B → 복원을 여러 번 반복해보기
3. 추측 상태 그대로 홈 이동 / 화면 잠금 / 앱 재실행 해보기
4. 난이도 2개 이상을 각각 저장한 뒤 번갈아 이어하기
5. 한 판은 실제로 끝까지 클리어해서 기록 반영 확인
