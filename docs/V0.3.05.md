# 야모네 게임 0.3.05

- 기준: release/0.3.04 (e3e2d3665a80e733079a162d2b87d516a060a2d6).
- 물고기·빙하 배경에 이번에 생성한 수중/오로라 일러스트를 실제 이미지 리소스로 적용.
- 기존 빙하 발판 모양과 착지 물리는 유지.
- 빙하: 누적 높이를 계산한 뒤 정수 cm로 저장, 표시/순위/공유는 0.01m 단위.
- 이전 빙하 정수 m 기록을 한 번만 cm로 변환. 예: 123m → 123.00m.
- 물고기 타임어택 플레이/메뉴/랭킹을 제거. 이전 최고기록은 숨긴 보관 키에 남겨 복귀를 방해하지 않음.
- 기기 기록은 게임별 최고 1개. 스도쿠는 난이도별 최단시간 1개. 완료 횟수 등 누적 통계는 유지.
- 최고기록 자동 전송으로 공유 ON/OFF 제거. 이전 OFF 상태도 새 정책으로 이관.
- 영속 대기열 + 네트워크 제약 WorkManager. 성공 응답 전에는 대기기록을 지우지 않음.
- 재시도 중 신기록은 더 좋은 값으로 합쳐지고 오래된 응답은 새 대기기록을 지울 수 없음.
- 스도쿠 서버 순위는 난이도별 최단시간(작을수록 높은 순위).
- 서버 배포 파일은 cloudflare/ranking-worker.js. 새 모드 도입은 운영 서버 배포가 필요함.
- 0.3.03의 홈/배너/선택 광고 정책과 스도쿠 강조, 0.3.04 눈덩이 개편 유지.

## 동기화의 범위
연결 시 앱 실행 중 즉시 재시도하고 백그라운드에서는 Android WorkManager가 실행 시점을 관리함.
기기를 강제 중지한 앱은 다시 실행해야 예약 작업이 재개될 수 있음. 앱 삭제 시 기기 데이터가 지워짐.
서버 오류/미배포 상태는 전송 완료가 아님. 큐를 유지하고 지수 백오프로 재시도함.

## 설치/복귀
package com.yamone.games, versionName 0.3.05, versionCode 30005.
서명은 기존 debug.keystore를 사용. 먼저 앱을 삭제하지 않고 업데이트.
복귀는 release/0.3.04를 같은 서명으로 versionCode 30006 이상 재빌드.
새 cm 빙하 기록은 구버전의 이전 m 보관 키를 덮어쓰지 않음.

## 그림
이미지 생성으로 만든 배경 원화를 좌/우로 분리하여 WebP 리소스로 넣음.
게임 UI를 그림에 그려 넣지 않으며 발판/물고기/조작 및 실제 충돌은 별도 레이어.
