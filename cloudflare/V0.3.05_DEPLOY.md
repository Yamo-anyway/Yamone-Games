# 0.3.05 서버 반영

수정 파일: `ranking-worker.js`. 기존 D1 테이블/서명 비밀키/기존 URL을 그대로 사용한다.
테이블 생성·삭제·초기화나 새 비밀키 생성이 필요하지 않다.

```sh
cd cloudflare
npx wrangler deploy
```

기존 배포 설정을 그대로 사용한다. 변경 후 `/health`의 `rankingProtocol`은 305다.
새 빙하 기록은 `ice_jump/height_cm`(정수 cm), 스도쿠는 난이도별 초 단위 최솟값이다.
기존 `ice_jump/normal`, `snow_rush/normal`, 예전 타임어택 데이터와 API는
이전 설치본을 위해 서버에 보존한다. 0.3.05 앱에는 타임어택 진입/랭킹이 없다.

앱은 게임·난이도별 최고기록 한 개만 자동 업로드하고 성공 응답을 받기 전까지
전송 대기열을 보존한다. 서버를 아직 업데이트하지 않았으면 새 모드의 기록은
전송 완료로 처리하지 않는다. 서버 반영 후 WorkManager 또는 다음 앱 실행에서 재시도한다.

온라인 삭제 기능은 선택한 서버 기록과 기기의 해당 최고기록을 함께 삭제한다.
오프라인 삭제나 서버 오류 때는 기기 최고기록을 그대로 둔다. 다음 플레이에서
새 기록이 생기면 다시 자동 전송된다.

검증: `node --test tests/ranking-precision.test.mjs` (Node 22.16+). 테스트는 메모리 DB만 사용한다.
